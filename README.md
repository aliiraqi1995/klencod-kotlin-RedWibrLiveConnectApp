# Red WIBR+ Live Connect (Android / Kotlin / Jetpack Compose)

مشروع تطبيق أندرويد باللون الأحمر يتيح تجربة الاتصال الفعلي بشبكة Wi-Fi عبر إدخال `SSID` وكلمة المرور ومتابعة حالة الاتصال المباشرة.

## هيكلية الملفات
- `settings.gradle.kts`
- `build.gradle.kts`
- `app/build.gradle.kts`
- `app/src/main/AndroidManifest.xml`
- `app/src/main/java/com/example/redwibrsim/MainActivity.kt`
